# 你的数据：导出、删除、带走

> 草稿版：正式发布前用试点客户的真实提问修订措辞。

产品、价格、客户、聊天记录、你的培训记录——都是你的。你的数据只用来帮你接待
客户，不给列在隐私政策里的服务商之外的任何人，也不拿去帮别的商家。

**导出**：在「设置 → 你的数据」里自己下载，不用找我们。每类一个表格文件（CSV），
表格软件可以直接打开：客户、消息、产品、订单、给过的价格、你的名单，以及你的价格
规则、你的销售条件和你教过的内容。每个文件最多 20000 行；更长的话跟我们说一声，
我们把其余的发给你。只有店主能导出。

**关闭工作台**（0126 起）：在「你的数据」最下面输入工作台的名字，按「关闭并清除这个工作台」。
确认后立即清除这个工作台里的一切——客户和对话、产品、订单、你教过的东西、每一个登录——
所有人都会被登出，无法撤销。先导出一份。付费方案还在运行时不能关闭：先在「账单」取消。
（本服务自己运行的那个工作台不能在这里关闭：按钮会请 Nomi 团队用同样的方式清除。）

**客户要求删除自己的数据**：打开这位客户的客户档案，按「立即删除这位客户的数据」，或在
「你的数据」的列表里按同一个按钮。客户在消息里提出、被认出来的，会自动记在那里，不用写
备注；用别的方式提出的（电话、邮件），写明对方是怎么、在什么时候提出的。只有店主能删除；
店员能看到状态。

- 删除立即生效，永久有效：数据被真正删掉，而不是隐藏。
- 会删除：对方在各个渠道上的身份、头像、双方往来的每一条消息、为对方准备的回复和价格
  以及样品申请（如有）、关于这些对话的备注，以及对话本身（订单需要的部分除外）。
- 会保留：对方下过的订单（不再关联联系方式和消息）；如果对方要求过不再联系，保留
  那个地址的一条记录；以及一条不含任何被删除内容的记录：对方提出过要求、何时完成。
- **Nomi 不会通知客户，需要的话请你自己告诉对方。**
- 不是删除要求的，可以按「不是删除要求」放到一边。

客户看到的说明在公开页面 `/data-deletion`：向你提出、你在 Nomi 里删除、立即生效；工作台
关闭时其中的一切都会被清除。备份里的副本会随备份到期删除；如果服务将来从备份恢复，之后
做过的每一次删除都会在服务运行之前重新执行。
