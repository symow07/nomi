# 你的数据：导出、删除、带走

> 草稿版：正式发布前用试点客户的真实提问修订措辞。

产品、价格、买家、聊天记录、你的培训记录——都是你的。你的数据只用来帮你接待
买家，不给列在隐私政策里的服务商之外的任何人，也不拿去帮别的商家。

**导出**：在「设置 → 你的数据」里自己下载，不用找我们。每类一个表格文件（CSV），
表格软件可以直接打开：买家、消息、产品、订单、你报过的价、你的名单，以及你的价格
规则、你的销售条件和你教过的内容。每个文件最多 20000 行；更长的话跟我们说一声，
我们把其余的发给你。只有店主能导出。

**删除整个工作台**：同样在「你的数据」里提出，要输入工作台的名字确认。这不是一个
按下去就清空的按钮：由 Nomi 运营方的人手动执行，执行之前你随时可以撤回。产品本身
不会自己删除任何记录——这是有意的设计（见 `PRODUCT.md`：只归档，不抹除）。删除之前
先导出一份。

**买家要求删除自己的数据**：打开这位买家的客户档案（「客户」列表里点这位买家），在
最下面的「删除这位买家的数据」里写明买家是怎么、在什么时候提出的，然后提交。只有
店主能提交；店员能看到状态。

- Nomi 运营方在你提交后的 30 天内手动执行。
- 会删除：对方在各个渠道上的身份、双方往来的每一条消息、为对方准备的回复、报价和
  样品申请、关于这些对话的备注，以及对话本身（订单需要的部分除外）。
- 会保留：对方下过的订单（不再关联联系方式和消息）；如果对方要求过不再联系，保留
  那个地址的一条记录；以及这次要求本身的记录。
- 执行完成后，客户档案和「你的数据」都会显示「已完成」和日期。**Nomi 不会通知买家，
  请你自己告诉对方。**
- 执行之前，可以在「你的数据」里撤回。

买家看到的说明在公开页面 `/data-deletion`：向你提出、你在 Nomi 里记录、运营方在
30 天内执行、完成后由你告知。
