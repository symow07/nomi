# 连接 WhatsApp：两步

> 草稿版：正式发布前用试点客户的真实提问修订措辞。

号码不用你填。帮你开通的人会先在主机上把号码设置好，你这边只需要按按钮。

第一步：打开「买家在哪里找你」，在 WhatsApp 卡片上点「连接这个号码」。
如果卡片上只有「连接」，说明号码还没设置好——按页面上的说明，
联系帮你设置的人。

第二步：连上以后点「测试连接」。它只检查连接是否正常，
不会给任何人发消息。

连上不等于开始接待：在「我的公司」让助手开始之前，一条消息都不会发出去；
开始以后，也只会发给你在「我的公司」名单里加过的号码。

连接状态在同一页看：已连接 / 需要处理 / 暂时异常 / 已断开。
出问题会直接告诉你怎么办，通常就是点一下「重新连接」。

不用 WhatsApp 也行：Instagram、Messenger 和邮箱都在同一页连接，
连上任意一个，「设置」里的这一步就算完成。
