# Settings redesign

Settings now has seven groups: Business, Channels, Assistant, Books, Team, Billing and Personal. Each subject has a focused page. On phones, native group and page choosers work with or without JavaScript. All screenshots use local synthetic records in English.

| Before | Now |
|---|---|
| My business, profile, type and selling | Settings → Business; Profile includes the complete original profile and separate business-type form |
| Closure dates and stated exchange rate | Business → Hours and Currency, beside the current profile values |
| Channel setup, test numbers and technical setup | Settings → Channels; test numbers are under WhatsApp |
| Assistant controls, identity and forbidden words | Settings → Assistant; permissions first, progress and reply types expandable |
| Assistant identity mixed into People | Assistant → Name; Team keeps people, access codes, permissions and hand-off rotation |
| Workspace advisor-history policy mixed with personal consent | Assistant → History policy and Personal → Advisor history |
| Browser, email and owner WhatsApp notifications | Personal → Notifications |
| Sample rules and customer requests together | Business → Samples for policy; Customers → Sample requests for daily handling |
| Books setup pages | Settings → Books, with the shared Settings navigation |
| Account, password, language and billing | Focused Personal pages and Billing |

Old GET bookmarks authenticate and redirect with their query. Original commands, downloads, callbacks and grants remain authoritative. The previous business-type GET occupies the new Business hub address; its editor is now in Profile and its original POST remains. No migration or business-rule change.
