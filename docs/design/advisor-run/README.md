# The advisor run — the assistant in Settings, the advisor's shell

Taken 2026-10-06 on a local instance (the demo workspace; Chromium, device scale 2), at 1280 px (desktop) and 390 px (phone), in en, zh, ar, es and fr.

- `settings-*`: Settings opens on the assistant. The row carries its own slot and its name, with how much it does alone, as it stands, on the line under it. My business and Setup follow.
- `assistant-*`: the assistant's page, one level into Settings (`/app/settings/assistant`). The control comes first and whole; then the same menu.
- `assistant-onekind-*`: one of its screens, a level further down.
- `advisor-*`: the advisor's shell in the rail's freed slot. It shows the opening line and the box.
- `advisor-asked-*`: the same page after a question. The question comes back once, with the placeholder reply; nothing is looked up or kept.

Every shot was checked by script: the right nav entry is lit, nothing is wider than its screen, Arabic is right to left, and the question is shown back.
