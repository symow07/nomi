# Approved Nomi redesign

The eight areas share warm paper, black actions, restrained magenta highlights and the unchanged seal. Daily work and configuration have separate navigation. Phone layouts retain the same actions and permission boundaries.

The [complete approved map](page-map.tsv) accounts for all 141 original pages and variants. The design gallery and the requested first-message refusal screenshot remain explicitly excluded. Guide-video frames were outside this inventory and were not redesigned. Original command, export, callback and signed public-link contracts remain authoritative; moved GET bookmarks redirect after authentication.
