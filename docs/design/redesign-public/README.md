# Public pages redesign

The public website uses flat sections and retains its existing example labels and live/draft distinction. Legal pages have a calm reading measure and clear section spacing. Customer proformas remain paper documents, and public chat keeps its original composer and send path.

All 19 public routes remain in place. No legal text, accepted-terms version, marketing claim, form contract, token validation or consent changes. All screenshots use English and local synthetic data.
