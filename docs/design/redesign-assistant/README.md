# Assistant redesign

Daily Assistant work now has six sections: Overview, Knowledge, Practice, Check replies, Activity and Ask Nomi. Configuration remains in Settings → Assistant. All screenshots use local synthetic records in English.

| Before | Now |
|---|---|
| Knowledge and product facts | Assistant → Knowledge, with Needs an answer, Taught facts, Products and Readings |
| Page readings and rereading | Knowledge → Readings, source sentence beside each unticked proposed fact |
| Sandbox and practice checklist | Assistant → Practice, with the checklist and readiness below the conversation |
| Assistant checks | Assistant → Check replies |
| Capability history | Assistant → Activity, alongside recorded checks and owner edits |
| Standalone Advisor and its history | Assistant → Ask Nomi and Earlier conversations |
| Authority and configuration | Settings → Assistant; daily Overview links there |

Old GET bookmarks authenticate and redirect. Original command routes, advisor allowance and privacy controls remain authoritative. Native forms retain refused teaching/correction text and filtered return context; signed Undo restores an archived fact.
