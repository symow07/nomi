# Assistant validation

## Browser comparison

The frozen final Books build and the final Assistant build run on separate owned loopback ports and cloned synthetic databases. The final comparison contains 35 states at 1440×900 and 390×844: 70 before visits and 70 after visits. It covers the 14 mapped legacy pages, new section views, source-reading states, complete paged lists, literal search, prefilled forms, staff/accountant and empty-owner states. New destinations are compared with their old source pages. The final after pass has no horizontal document overflow or browser page errors. Comparison captures are English-only.

Nine read-only groups pass. Browser paging reaches all 12 products, 120 taught facts, 109 readings and 110 activity records (capability events plus checked replies and owner-edited drafts), across 1/3/3/3 pages. Database tests independently cover more than 200 products, stable same-time paging, literal wildcard characters, clamped pages and cross-tenant isolation. The browser's product fixture is twelve records; it is not represented as the larger database fixture.

Tests verify filtered-list return, unticked source proposals, reviewed/replaced readings, exact recorded reply evidence and original verdict command, usable phone navigation, Escape handling, native controls without JavaScript, the Ask field above 600 px and Practice composer above 750 px, 44 px message controls, and source text above the proposed fact on phones.

Ten source/authority tables in each clone have unchanged counts and hashes after read-only passes. The comparison and proof precede deliberate command tests.

## Actual local commands

Six browser workflow groups pass: invalid teaching retains exact text and label, valid teaching adds one fact; invalid correction preserves its input, valid correction changes the same fact; archive plus signed Undo restores the fact and filtered return; an explicit scripted reading proposes two unticked facts and only the selected fact is taught; Ask Nomi uses its original advisor and displays Customers: 15, matching an independent count of non-testing customer conversations; and Right records the original correct verdict without sending.

The Ask check waits for the native details opening transition before inspecting visible evidence. During diagnosis, five questions used the local scripted advisor (ten recognise/phrase calls). One scripted page read ran. External fetch and outbound kick counters stayed zero. No live model was used.

Refused command fields are escaped, retained and marked; invalid external return URLs fall back to the local Knowledge page. Signed Undo accepts only the known restore command and bounded encoded Knowledge return. An overlong return falls back to the original restore command, preserving Undo.

## Repository verification

Node 22 check passed 9,299 assertions, trust passed 44, and build passed. Both the first and final full isolated integration runs passed 2,067 of 2,067 with none skipped. The final run tested the frozen source after incorporating the Books merge (971.62 seconds). Exact-head CI and the gated merge remain separate release requirements.

## Limits

The local preview uses disabled messaging, no workers, blocked external fetch and scripted page/advisor ports. Practice browser checks cover the real form and controls; integration tests cover the private-copy queue/worker behavior. There were no paid reads, real connector calls, production changes or customer sends. Permission, allowance, grounded read-only advisor, history consent, Stop and earned-autonomy decisions still use their original services.
